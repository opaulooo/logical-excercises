Two Sum Variant

Given an integer array and target, return indices of the first pair that sums to target in O(n).

Group Transactions by Category

Aggregate transaction amounts by category, ignoring invalid amounts and handling category case-insensitively.

Easy #03

Count Vowels

Return how many vowels appear in a string, considering uppercase and lowercase letters.

Easy #04

Palindrome Check

Check whether a text is palindrome ignoring spaces, punctuation, and case.

First Non-Repeated Char

Find the first character that appears only once in a string.

FizzBuzz Range

Print Fizz, Buzz, or FizzBuzz for numbers from 1 to n.

Remove Duplicates

Given an array, return a new array preserving order and removing duplicates.

Valid Anagram

Reverse Words

Merge Sorted Arrays
